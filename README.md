# MemorEmoji - Memory Card Game

MemorEmoji is a card game where players need to match pairs of cards with the same emoji or symbol. This project was created as part of the Applied Internet Technology course.

## Game Features

- Customizable number of cards (4-36, must be even)
- Customizable maximum number of turns
- Option to preset card values for testing
- Responsive card grid that adjusts based on the number of cards
- Turn tracking
- Match/no match feedback
- Win/lose conditions
- Play Again functionality

## How to Play

1. Enter the number of cards you want to play with (must be an even number between 4 and 36)
2. Enter the maximum number of turns (must be at least half the number of cards)
3. Optionally, you can enter specific card values for testing
4. Click "Game Start" to begin
5. Click on cards to flip them over
6. Try to find matching pairs
7. After flipping two cards, you'll see if they match or not
8. Click "OK" to continue to the next turn
9. The game ends when either all cards are matched or you reach the maximum number of turns
10. Click "Play Again" to start a new game
